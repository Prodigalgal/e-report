# ADR：APK 仅通过 R2 分发

- 日期：2026-08-09
- 状态：已接受并投产
- 替代：APK 在 R2 失败时回退到 VPS/relay 源文件下载

## 决策

Android stable 安装包使用固定公网入口 `https://e-report.fantong.eu.org:60443/download/android`。该入口只查询最新版本元数据并返回到 348 账号的不可变 R2 对象的 `302`，APK 字节流不经过 VPS。

- 版本 API 只返回固定入口，不返回 `apkFallbackUrl`。
- 后端不再暴露按发布 ID 读取本地 APK 的公开接口。
- R2 公开基址缺失时，统一下载入口返回 `503`，不回源。
- APP 解析一次固定入口后，仅对同一 R2 地址做 2 MiB 分片、4 路并发和单片最多 5 次退避重试。
- 发布归档可保存在 VPS 持久卷，仅供管理员重新同步 R2，不作为用户下载数据面。

## 原因

- VPS 出口带宽只有约 10 MB，一个约 76 MB 的 APK 即可长时间占满出口，并影响登录、工单、附件和通知 API。
- 客户端自动回退会在 R2 故障时将所有升级用户同时导向最弱的 VPS 链路，放大故障。
- R2 原生支持 `HEAD`、`Range` 和 CDN 分发，已能满足断点、并发分片和完整性校验。

## 失败语义

R2 暂时不可用时，当次升级失败，APP 显示可重试的中文提示并保留当前可用版本。每个分片只向 R2 重试，不切换主机。动态 API 的主备域名机制与 APK 下载数据面分离。

## 回滚

后端可回滚到发布前镜像，但不建议恢复 APK 回源。Android 客户端不能降低 `versionCode`；如 code37 存在问题，使用相同生产签名发布更高 code 修复版。
