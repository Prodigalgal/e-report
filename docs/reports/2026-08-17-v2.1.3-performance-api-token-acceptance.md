# 2.1.3 性能、API Token 与 AI Guide 验收报告

## 结论

`2.1.3/code1001003` 已完成本地构建、独立测试命名空间、真实 WEB、Android 16 模拟器、只读压力、供应链与生产 smoke 验收。`2.1.0`、`2.1.1`、`2.1.2` 分别因 acceptance 依赖锁、入口迁移脚本、release 依赖锁缺陷被拒绝提升；修复后的 `2.1.3` 使用同一不可变 Backend/WEB 镜像和签名 APK 提升生产。

## 功能验收

- API Token：创建、一次性明文、列表脱敏、有效期/长期、权限子集、撤销、过期、篡改、用户状态与授权动态收缩均由统一授权引擎约束。
- AI Guide：`GET /api/ai/guide` 只接受 API Token，按当前有效 permission key 返回能力目录；测试 Token 仅得到工单查询和详情能力。
- 越权阻断：Token 不能访问用户管理、Token 管理和交互式认证接口；数据域与资源关系继续继承用户有效 Grant。
- WEB：桌面与 390px 移动视口完成名称、长期/限时切换、权限搜索、创建、一次性明文和撤销流程，无控制台错误和横向溢出。
- APP：Android 16 模拟器完成真实登录、个人中心、权限搜索、30 天 Token 创建、一次性明文、撤销与精确清理；设备信息显示为模拟器真实型号和 Android 版本。
- 测试数据：所有 `E2E-API-TOKEN-*`、`WEB-UI-E2E`、`APP-E2E-213` 记录及关联权限均在对应 namespace 精确删除，未创建工单或通知。

## 性能与入口

- VPS 公网入口由单连接积压较小的转发进程切换为 HAProxy + PROXY v2，`backlog/maxconn=4096`，真实 IP 继续由 Gateway 受信代理策略解析。
- 三轮叠加负载和一轮完全隔离基线均无 429、5xx 或连接错误。
- 隔离基线：登录主体约 262ms；工单查询并发 20/100 请求 `p95=571ms`；用户列表为最慢读取，`p95=908ms`；其余核心读取 `p95` 约 508-663ms。
- Backend/WEB 测试 Pod Ready、重启 0；HAProxy 正式入口三轮公开探测均为 0 错误。

## 供应链

- 供应链契约、npm audit、Gradle lock/checksum、Gitleaks、CycloneDX SBOM 和 OSV Release 扫描通过。
- Release 运行依赖 OSV 发现为 0；APP 的 14 个 npm package/28 个 advisory 均为已有、逐项登记的 Metro 构建期例外；构建工具链基线 254 项不进入运行制品。
- 本机没有 Docker/containerd，最终候选未在本机重复执行容器扫描；服务器构建使用固定 digest 基础镜像，OCI 与 SBOM 均完成 SHA-256 校验。

## 遗留观察

- `admin.users` 在并发读取下仍是最慢链路，后续优化应优先继续收敛用户列表投影与授权摘要装配，但当前错误率和延迟满足本轮发布门禁。
- Expo/RN 上游仍有 Gradle 10 兼容性和 deprecated API 编译警告；本版本构建成功，不在当前版本降级 Expo/RN，后续依赖升级专案处理。
