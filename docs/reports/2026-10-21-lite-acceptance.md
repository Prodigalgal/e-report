## 已发现并处理

- 补齐 WebView 的 `alert` / `confirm`，避免管理页面的确认操作无响应。
- 补齐录像入口、视频全屏和系统返回；旋转由当前 Activity 处理，保留 WebView 表单与文件选择状态。
- 位置分享使用系统分享面板，个人 Token 复制使用原生剪贴板并标记敏感内容。
- Lite 升级大小字段与公开 API 的 `apkSize` 对齐；原生版安装前增加实际包名、版本递增和签名校验。
- 拒绝系统定位权限触发 WebView 重复请求：权限回调改为合并等待者、先清理再派发，WebView 暂停从 `onPause` 移至 `onStop`，避免权限弹窗中断正在等待的定位。新增并发及重入测试，设备验证拒绝、再授权和地址回填通过。
- 图片整体页面缩放导致关闭按钮离开视野：WEB/Lite 增加局部缩放、边界拖动、双击与缩放/还原按钮，复用原生版相同几何逻辑；固定对话框操作区域。待候选上线后实际触控复验。
- R2 公开地址误指向应用站点，APK/OTA 下载得到 HTML：通过 Cloudflare 桶配置查询确认 `download.omnnu.xyz` 为现有启用域名，29 份 OTA 资源真实下载摘要全部正确，两个 APK HEAD 大小和类型正确。GitOps 自动更新时修复公开下载地址；新增 APK HEAD、Range 与全量 SHA-256 门禁，包括复用已登记版本，避免仅查登记记录就误报发布成功。
