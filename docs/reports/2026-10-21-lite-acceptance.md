# Lite 测试环境功能验收

## 验收边界

- 候选：业务 `6.8.0`，原生版与 Lite 基础包 `6.8.0` / `5008000`。测试环境发布，不提升生产。
- Lite 复用完整 WEB 业务权限与 API，检查移动 WebView 实际交互，不能以桌面网页通过代替 APK 验收。
- 两款分别升级，不在应用内互转；更换类型先卸载当前客户端，再下载另一款。
- 真实写入限定测试环境和明确标记的验收对象；生产仅核对版本，测试账号、工单和附件与真实业务隔离。

## 已发现并处理

- 补齐 WebView 的 `alert` / `confirm`，避免管理页面的确认操作无响应。
- 补齐录像入口、视频全屏和系统返回；旋转由当前 Activity 处理，保留 WebView 表单与文件选择状态。
- 位置分享使用系统分享面板，个人 Token 复制使用原生剪贴板并标记敏感内容。
- Lite 升级大小字段与公开 API 的 `apkSize` 对齐；原生版安装前增加实际包名、版本递增和签名校验。

## 验证记录

- WEB / APP / Backend / Lite 编译、自动测试和设备结果分别记录；未执行项目保持待验收，不将源码检查视为真实功能测试通过。
- Pixel_9 / Android 16（API 36），已安装本地签名 Release，使用测试站真实 API。云端候选尚未部署时，以下业务验收连接的是测试站现有 WEB / Backend，候选上线后仍需复核。
- 管理员登录后，在 Lite 创建专属验收用户；中文输入、组织搜索选择、手机号与密码校验通过。追加“全类型提单员”岗位模板，预检新增 21 项、应用后有效 29 项，授权版本从 2 升至 3。
- 编辑该验收用户姓名并保存，详情回读一致。四类邮件通知全部关闭，保存并关闭弹窗后重开仍为关闭。账号停用及恢复均成功，授权版本相应推进。未更改其他真实用户或超管的资料、通知偏好。
- 验收用户首次登录被引导设置个人密码；修改成功后清除会话并返回登录页。其余登录边界、重启恢复及后续业务闭环继续验收。
- 云端门禁发现并修复：补齐 Lite 的 Linux 依赖校验；原生 KSP `symbol-processing-aa-embeddable` JAR 与 Maven Central 实际 SHA-256 核对后登记。失效的 Docker 镜像加速域名改为官方仓库，两个基础镜像的不可变 digest 保持不变，并通过官方 Registry manifest 校验。
- 发布工具 20 项测试、版本契约及供应链契约通过；KSP Release 任务在严格校验配置下成功。云端制品和自动部署仍须单独确认。
