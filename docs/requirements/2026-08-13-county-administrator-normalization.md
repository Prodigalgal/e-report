# 区县管理员组织与授权规整

## 目标

- 将示例管理员甲、示例管理员乙规整为南靖县管理员，将示例管理员丙规整为漳浦县管理员。
- 统一使用内置 `COUNTY_ADMINISTRATOR` 岗位规则，消除历史迁移留下的市级、区县和平台职责混杂。
- 保持权限面限制动作、数据面限制视野、组织面表达人员归属，三者通过岗位 Grant 规则明确关联。

## 范围

- 示例管理员甲、示例管理员乙继续归属南靖县；示例管理员丙从南靖县迁至漳浦县。
- 三人的角色和 Grant 精确重建为区县管理员标准岗位的 32 项职责。
- `ROLE_USER` 使用所属区县 `ORG`，其余职责使用所属区县 `ORG_TREE`，均为永久授权。
- 移除市公司通知、SLA 编辑、安装包发布/策略/存储、租户创建和租户状态管理等超出区县岗位的职责。
- 补齐区县通知收件人和 SLA 查看员等标准区县职责。
- 迁移前快照用户组织、`user_roles` 和 `membership_role_grants`，并递增授权版本。

## 非目标

- 不修改三人的账号、密码、手机号和邮箱。
- 不迁移历史工单的组织归属；工单保留创建时的业务归属事实。
- 不修改吕春珉、默认管理员或其他用户。
- 不修改 APP/Web 页面或发布新的 Android 安装包。

## 验收标准

- 示例管理员甲、示例管理员乙归属南靖县；示例管理员丙归属漳浦县。
- 三人各持有且仅持有 `COUNTY_ADMINISTRATOR` 的 32 项角色和 Grant。
- 三人的仪表盘范围接口返回空区县选择列表；统计结果只覆盖各自所属区县组织树。
- 三人显示为“区县管理员”，不能查看或委派市级、平台级角色和数据范围。
- `admin`、吕春珉和其他用户的组织、角色、Grant 与授权版本不变化。
- Liquibase 首跑、幂等重跑、完整后端测试、隔离测试环境登录与生产只读断言全部通过。

## 回滚

- 优先恢复生产迁移前整库备份。
- 单迁移回滚时，从三张 032 快照表恢复组织、`user_roles` 和 RoleGrant，并递增授权版本使旧会话失效。
