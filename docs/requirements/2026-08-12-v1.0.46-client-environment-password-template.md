# 1.0.46 客户端环境、安全与导入模板修复

## 目标

- 将 WEB/Android 的设备与运行环境采集收敛为版本化契约，为登录风险判断、会话治理和错误排查提供一致证据。
- 管理员重置密码必须前后端同时校验两次输入一致。
- 修复用户导入模板中文文件名乱码和 OOXML 被 Excel 提示修复的问题。
- 清理 Expo ImagePicker 已废弃 API，避免无业务价值的运行诊断告警。

## 范围

- WEB `web-env-v1`：Navigator/Client Hints、浏览器与操作系统、Canvas、WebGL/GPU、Web Audio、候选字体、时区语言、屏幕与输入能力、自动化风险信号。
- Android `android-env-v2`：Keystore 安装身份、系统/安全补丁、SoC/ABI、屏幕、内存/存储档位、安装来源、应用签名及 root/模拟器/调试/Hook 等信号。
- 认证挑战绑定客户端环境摘要；WEB 会话保存规范化环境 JSON，Android 可信设备保存环境摘要。
- 运行诊断复用同一环境采集结果，只在 ERROR/WARN 或用户主动诊断时上传详细上下文。
- WEB 用户列表、WEB 用户详情、Android 用户详情统一使用“新密码 + 确认新密码”。

## 非目标

- 不采集 IMEI、真实 MAC、设备序列号、Android ID、广告 ID、SSID/BSSID 或精确坐标。
- WEB 指纹不是可信硬件证明，不能单独决定封禁、授权或身份认证；指纹漂移只提高风险等级。
- 不上传 Canvas 原图、Audio 原始波形或系统全量字体枚举；仅上传 SHA-256 摘要、允许列表命中项和能力状态。
- 不在本版本重构用户导入的业务模式、异步任务或回滚机制。

## 契约与迁移

- `AuthChallengeRequestDTO.webFingerprintHash` 与 `LoginRequestDTO.webEnvironment.fingerprintHash` 必须在 WEB 挑战和登录间一致。
- `auth_sessions` 新增 WEB 环境摘要、展示字段、风险信号和 JSON；`trusted_devices` 新增 Android 环境摘要、SoC/ABI/低内存字段。
- 所有新增字段可空，保证历史会话和可信设备可读；1.0.46 客户端开始写入，旧数据不伪造回填。
- 管理员密码重置请求契约变为 `{ newPassword, confirmPassword }`，两字段均必填且必须相同。

## 验收标准

- Windows WEB 诊断显示浏览器及 Windows 版本，不再显示 `版本 web · 系统 Win32`。
- 支持 Client Hints 的浏览器上传高熵环境摘要；不支持或拒绝时有明确 capability/signal 且登录不受阻。
- Canvas/WebGL/Audio/字体任一采集失败均在 2 秒内降级，不阻塞首屏和登录。
- Android 登录的可信设备记录包含 `android-env-v2` 摘要，诊断上下文复用设备安全信息且不泄露禁止标识。
- 三个管理员重置密码入口均要求两次输入；绕过客户端直接调用接口时，后端拒绝不一致密码。
- 模板响应包含 RFC 5987 UTF-8 文件名；生成的 `.xlsx` 可被 Apache POI、工作区表格工具和 Microsoft Excel 无修复提示打开。
- WEB/APP 测试、构建、Android release 构建及模拟器 smoke 通过；版本统一为 `1.0.46` / `versionCode 46`。

## 测试方式

- Backend：DTO validation、挑战绑定、会话环境、下载响应头、用户导入集成测试及全量 Gradle test。
- WEB：环境解析/摘要、密码确认、Telemetry、文件下载测试，随后 lint/build 和浏览器 smoke。
- APP：密码策略/API、设备上下文与废弃 API 静态策略测试，typecheck/test/Expo Doctor/Gradle release 和模拟器登录 smoke。
- 数据：Liquibase MySQL/H2 migration test；部署候选环境后核对 `auth_sessions`、`trusted_devices` 与诊断事件字段。
