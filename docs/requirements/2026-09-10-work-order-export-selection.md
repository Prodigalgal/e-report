# 工单导出选择与数据域约束

目标版本：`5.8.0`

## 目标

WEB 工单查询导出支持按用户明确勾选的工单生成电子表格，并由服务端再次校验每个工单是否处于当前账号的租户、组织和工单类型数据域内，不能通过篡改请求导出其他区县数据。

## 范围

- WEB 工单列表提供跨分页的工单勾选、当前页全选和清空选择。
- 导出请求增加重复 `workOrderId` 参数；未选择时保留既有按筛选条件导出的接口能力，WEB 按钮仅允许导出已选工单。
- Backend 在导出查询中将所选 ID 与既有工单导出权限、组织树、提单人和参与关系条件取交集；任一所选 ID 不在当前数据域时拒绝整个导出。
- 导出过程按批次读取，校验查询结果与所选集合一致，避免并发变化造成静默漏导。

## 非目标

- 不新增工单权限类型，不改变现有导出权限和工单列表可见性语义。
- 不提供 APP 导出入口，不允许前端单独决定数据域。
- 不改变历史工单的组织归属或责任部门。

## 验收标准

1. WEB 当前页可全选/取消，翻页后已选项保留，筛选条件重新提交时清空旧选择。
2. 导出按钮显示已选数量，仅导出勾选的工单；文件行数与选择数一致。
3. 请求注入其他区县工单 ID 时，Backend 返回拒绝且不生成文件；同租户但不在授权组织/关系范围的 ID 同样拒绝。
4. 选择的工单在导出前已被删除、转出数据域或不再匹配筛选条件时，整个导出失败并提示刷新，不输出部分文件。
5. 既有筛选条件、多选状态、分页、XLSX 校验和导出权限回归测试全部通过。
