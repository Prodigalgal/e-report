# 2.4.0 系统级安装包发布中心

> 本候选在测试迁移后被 2.4.1 取代；“仅超级管理员且不可委派”的授权结论不再生效。现行规则见 `2026-08-19-v2.4.1-system-app-release-delegation.md`。

## 目标

- 将安装包发布中心从租户授权模型中剥离，限定为 `SUPER_ADMINISTRATOR` 系统身份专用能力。
- WEB 提供 APK 分片上传、发布进度、最新版下载和指定版本下载。
- 发布记录保持全局唯一，不受租户或组织数据域影响。
- 测试环境使用独立 R2 对象前缀，禁止测试安装包覆盖生产对象。

## 范围

- Backend：系统身份鉴权、发布登记、指定版本下载、R2 隔离前缀、同步成功后发布。
- WEB：发布弹窗、断点续传、上传进度、逐版本下载和明确错误态。
- APP：发布中心入口和既有发布操作改为仅超级管理员可见。
- Data：Liquibase 回收历史 `app-update:*` 租户授权并退役发布岗位模板。
- Deploy：测试和生产分别配置 R2 对象前缀；密钥继续由 Kubernetes Secret 注入。

## 非目标

- 不迁移现有 R2 存储桶或 Cloudflare 账号。
- 不允许普通管理员通过原子权限、岗位模板或 API Token 获得发布中心权限。
- 不改变公开的最新版下载入口 `/download/android`。

## 关键契约

- 系统能力：`system:super-administrator`，由 `users.system_key` 运行时派生，不进入权限目录和授权编辑器。
- 发布版本遵循 SemVer；Android `versionCode=(x-1)*1000000+y*1000+z`，`runtimeVersion=android-x.y.z-native<versionCode>`。
- 新发布记录初始为未发布；R2 同步成功后才标记为已发布并参与最新版计算。
- 测试对象前缀为 `e-report-test`，生产沿用现有无前缀对象路径。

## 影响文件

- `e-report-backen`：鉴权、发布、R2、文件传输、Liquibase 与测试。
- `e-report`：发布中心页面、路由、菜单、上传与下载交互。
- `e-report-app`：系统身份权限常量及发布中心入口。
- `deploy/dedicated-cloud`：R2 环境隔离配置。

## 验收标准

- 超级管理员可查看、上传、修改策略、同步、删除和下载指定版本。
- 默认市公司管理员及任何租户管理员均看不到入口，直接调用接口返回 403。
- API Token 即使由超级管理员创建，也不能访问发布中心。
- 上传中断可续传；错误信息区分文件校验、版本冲突、R2 未配置和同步失败。
- 未同步完成的版本不出现在客户端最新版检查中。
- 测试发布只写入测试前缀，清理测试对象不会触碰生产对象。

## 测试方式

- Backend 单元/集成测试覆盖系统身份、API Token 拒绝、版本契约、发布状态和 R2 前缀。
- WEB 测试覆盖上传参数、分片续传、下载链接、权限隐藏、错误态和 loading。
- APP typecheck、测试、Expo Doctor、Android release 构建与版本契约校验。
- 测试命名空间执行上传、同步、逐版本下载、客户端更新检查与无副作用数据核对。
