# v5.6.7 媒体脱敏运行时修复任务规格

## 目标

修复 v5.6.6 候选在 slim Python 基础镜像中导入 `cv2` 时缺少 `libGL.so.1` 导致媒体 worker 无法启动的问题，重新生成不可变的 v5.6.7 候选，并按测试环境通过后再晋级生产环境。

## 范围

- 媒体 worker 镜像仅补充 `libgl1` 运行时库，不改变脱敏模型、OCR 目标范围和异步处理契约。
- Backend、WEB、APP、数据库迁移和镜像统一递增到 `5.6.7`；Android `versionCode` 使用 `4006007`。
- 测试命名空间重新滚动部署，验证 worker 启动、后端迁移、前端入口、脱敏回归、错误日志和通知隔离。
- 测试闭环通过后使用同一不可变镜像晋级生产，保留部署前快照与回滚镜像。

## 非目标

- 不改变品牌识别规则：只处理中国移动中文、英文和 logo；不因颜色、二维码或普通文字触发。
- 不启用测试数据同步、不向测试或生产新增测试工单、通知或邮件数据。

## 验收标准

1. media worker Pod 处于 `Ready`，日志无 `libGL.so.1`、OCR 初始化或模型校验异常。
2. Backend、WEB、APP 版本契约一致，数据库迁移幂等完成。
3. 正样本均能命中，法国军旗、普通文字、二维码、3G 等硬负样本零误检。
4. 测试和生产入口 smoke、回滚快照、SBOM/供应链审计结果均留痕。
