# 1.0.42 工单查询体验与独立测试命名空间

## 目标

- 修复工单查询中 SLA 风险标签与倒计时重复显示的问题，例如不再出现“已超时 · 已超时 3小时7分钟”。
- 统一 Web 与 Android 工单查询的标签高度、图标命中区、文字基线、状态区宽度和窄屏换行行为。
- 增加不暴露公网的 `e-report-test` 命名空间，定时从生产数据库同步可用于回归测试的数据。

## 范围

- Web `WorkOrderTable` 及其展示契约、SLA 文案函数和对应测试。
- Android 工单卡片、展示 Badge、SLA 文案函数和对应测试。
- `deploy/dedicated-cloud/e-report-test.yaml`：独立 MySQL、Redis、后端、前端、同步 CronJob 和最小 RBAC。
- `deploy/dedicated-cloud/setup-test-namespace.sh`：创建测试密钥、应用资源、执行首次同步的运维入口。

## 非目标

- 不修改生产数据库结构，不新增 Liquibase changeset。
- 不给测试命名空间配置 Gateway、DNS 或公网入口。
- 不把生产通知、邮件、钉钉、企业微信、出站事件、客户端观测数据带入测试空间。

## 同步边界

同步使用生产 MySQL 的 `mysqldump --single-transaction --quick` 只读导出，导入测试 MySQL 后清理：

- `outbox_events`
- `daily_work_order_report_dispatches`
- `client_observation_events`
- `command_idempotency_records`
- `file_transfer_upload_sessions`

测试后端使用 `e2e` profile 和显式关闭通知、出站、日报调度、Liquibase 的环境变量；同步期间由 CronJob 先缩容测试后端，清理 Redis，再等待后端滚动恢复。

## 验收标准

- Web/App 单元测试覆盖正常、暂停、超时、完成 SLA 文案，证明风险标签不会重复。
- Web 构建、App 测试、类型检查和 Android 版本契约通过。
- `e-report-test` 的 MySQL、Redis、后端、前端 Ready；首次同步 Job Complete。
- 测试库工单/用户数量与生产同步时一致，五类出站/观测表为 0，测试 Redis 为空。
- 测试空间只能通过集群内 Service 或显式 `kubectl port-forward` 访问，生产数据和生产通知链路无写入。
