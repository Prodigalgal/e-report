# 2.1.3 API Token 与 AI Guide 规格

> 历史规格：`GET /ai/guide` 已由个人 MCP 工具发现替代，并从当前 API 契约删除。此文件仅记录旧版实现背景，不再指导新实现。

## 目标

允许已完成首次密码修改的用户通过交互式 WEB/APP 会话创建个人 API Token，供 LLM、自动化脚本和受控 API 集成使用。Token 可配置有效期或长期有效，并只能持有用户主动选择且当前实际拥有的原子权限。

## 范围

- Liquibase 新增 `api_tokens` 与 `api_token_permissions`，主键统一使用 UUIDv7/BINARY(16)。
- Backend 新增 Token 创建、列表、可选权限、撤销、Bearer 认证、动态授权交集、限流和最后使用时间。
- Backend 新增 `GET /ai/guide`，只接受 API Token，按 Token 当前有效权限裁剪返回机器可读的使用指南。
- WEB/APP 个人中心新增 API Token 管理：名称、有效天数/长期、权限搜索与多选、一次性明文展示、复制、状态和撤销。
- 更新三端版本、Android `versionCode`、镜像/SBOM/发布记录为 `2.1.3` / `1001003`。`2.1.0` 测试候选因新增原生依赖未进入 Gradle dependency lock 被拒绝提升；`2.1.1` 测试候选暴露入口迁移脚本状态判定与 systemd 运行目录缺陷；`2.1.2` 正式 APK 构建发现 `expo-clipboard` 未锁定 release classpath，三个候选均不得发布。

## 非目标

- 不引入 OAuth Authorization Server、第三方身份提供商、MCP Server 或新的重型网关。
- 不允许 API Token 创建、修改或撤销其他 API Token，也不允许调用登录会话管理接口。
- 不复制用户 Grant、数据域或资源关系，不让 Token 在用户权限收回后继续保留历史权限。
- 不在响应、日志、数据库、Redis、运行诊断或观测事件中持久化 Token 明文。
- 本版本不提供管理员代替用户创建 Token；Token 所有者只能管理自己的 Token。

## 核心授权规则

每次 API Token 请求都使用当前用户授权快照计算：

```text
有效 Grant = 用户当前有效 Grant
           ∩ Token 创建时选择的 permission key
           ∩ 当前请求对应的资源、组织数据域和资源关系
```

- Token 不保存独立数据域；被保留的 Grant 继续携带原组织范围、资源关系、`validFrom` 和 `expiresAt`。
- 用户、租户停用时 Token 认证失败；用户授权版本变化后下一次请求直接使用新的授权快照。
- Token 权限可以因用户授权收缩而减少，不能因用户后来新增权限而自动增加；只有创建时选择过的 permission key 才可能生效。
- Token 自身过期或撤销后不可恢复；需要继续使用时创建新 Token。

## Token 契约

- 格式：`erpt_<uuid>.<base64url-secret>`。
- secret：32 字节 CSPRNG；数据库仅保存 `HMAC-SHA256(namespace, secret)`，比较使用常量时间算法。
- 名称：1-80 个字符；同一用户最多 20 个未撤销且未过期 Token。
- 权限：至少 1 个、最多为当前有效权限全集；后端拒绝未知或越权 permission key。
- 有效期：`expiresAt` 可空；非空时必须晚于当前时间，最长不超过 10 年。
- 使用记录：`lastUsedAt` 最多每 5 分钟写回一次，避免每个请求产生数据库写 I/O。
- 限流：默认每 Token 每分钟 300 次，通过配置调整；Redis 不可用时 fail closed，不绕过限流。

## API 契约

| Method | Path | 凭据 | 行为 |
| --- | --- | --- | --- |
| `GET` | `/api-tokens` | 交互式会话 | 列出当前用户最近 100 个 Token，不返回 secret/hash |
| `GET` | `/api-tokens/options` | 交互式会话 | 返回当前用户可选择的原子权限及中文名、读写模式、风险等级 |
| `POST` | `/api-tokens` | 交互式会话 | 创建 Token；明文只在本次响应返回 |
| `DELETE` | `/api-tokens/{id}` | 交互式会话 | 撤销当前用户自己的 Token，幂等返回 204 |
| `GET` | `/ai/guide` | API Token | 返回 Token 当前有效权限和可调用能力指南 |

错误模型沿用全局 `ApiErrorResponseWriter`。无效、过期、撤销或格式错误的 Token 统一返回 401，不区分具体原因；越权返回 403；超限返回 429。

## AI Guide 响应

响应至少包含：

- `schemaVersion`、`apiVersion`、`basePath`。
- Bearer Header 写法、Token 到期时间、限流说明和明文安全约束。
- 当前实际有效的 permission key、中文名、描述、读写模式和风险等级。
- 只按当前权限返回的能力族：工单查询/详情/流转/附件、报单、接派调单、回单、验收、仪表盘和已支持的管理 API。
- 各能力的 method、path template、所需任一权限、用途和高风险操作提示。
- `requestId`、幂等、附件和分页约束；不返回其他用户、其他租户或未授权能力目录。

## 数据模型与索引

`api_tokens`：`id`、`tenant_id`、`membership_id`、`name`、`secret_hash`、`created_at`、`expires_at`、`last_used_at`、`revoked_at`、`revoke_reason`。索引覆盖 `(tenant_id,membership_id,created_at)`、`expires_at`，并对 `secret_hash` 建唯一约束。

`api_token_permissions`：`token_id`、`permission_name` 联合主键；分别外键到 `api_tokens.id` 和 `permissions.name`，Token 删除采用级联，权限目录仍保持固定契约。

## 安全与观测

- Authorization Header 必须使用 `Bearer`，Token 不允许放在 URL/query。
- 日志只记录 Token UUID、membership UUID、请求 ID 和结果，不记录 secret 或 Authorization Header。
- Token 管理 API 只接受 WEB/APP 交互式会话；首次密码未修改时继续由现有过滤器阻断。
- API Token 不走 WEB CSRF，也不伪装 Android 设备签名会话；两类认证链互不替代。
- 创建和撤销进入操作审计；连续 401/429 由现有轻量观测链路定位。

## 验收标准

- 越权 permission key、他人 Token 撤销、过期 Token、已撤销 Token、篡改 secret、用户停用和权限收缩全部被阻断。
- 数据域和资源关系测试证明 Token 无法看到用户本人通过相同 permission key 也看不到的数据。
- 创建响应之外的列表、日志、数据库与缓存均找不到明文 Token。
- AI Guide 只返回 Token 当前有效能力；API Token 无法访问 `/auth/**` 和 `/api-tokens/**`。
- 后端全量测试、WEB/APP 测试/构建、Liquibase MySQL 8.4 首次/幂等、真实 API smoke、限流和撤销即时生效通过。
- 先部署 `e-report-test`；如测试后改动任何 deployable 代码，版本必须继续递增。测试全部通过后才提升同一不可变制品到生产。

## 回滚

- Backend/WEB 回滚到 `20260816-v2.0.1-performance-test-1` 或上一生产不可变镜像。
- Liquibase rollback 先删除 `api_token_permissions`，再删除 `api_tokens`；回滚将永久撤销已创建 Token。
- APP 只能发布更高版本修复，不能复用已被测试候选占用的 `versionCode=1001001`、`1001002` 或 `1001003`。
