# 2.2.0 登录会话与交互性能

## 目标

- Android 在本地会话仍有效时，冷启动自动通过 Refresh Token 恢复登录，不因 Access Token 过期要求重新登录。
- WEB 提供“记住登录状态”，选中后保持 7 天持久会话，未选中时仅保留当前浏览器会话；客户端不保存密码。
- 保持现有 PoW 难度和设备证明协议不变，消除逐次异步摘要调用造成的客户端等待。
- 登录和长耗时提交提供稳定的加载状态，防止重复提交并让用户知道当前进度。

## 范围

- Android 认证请求刷新策略、PoW 计算、登录阶段反馈和共享按钮加载态。
- WEB 登录表单、登录请求 DTO、WEB 会话 Cookie 生命周期和 PoW 计算。
- Backend、WEB、APP 统一升级到 `2.2.0`，Android `versionCode=1002000`。

## 非目标

- 不降低密码哈希参数、PoW 难度、验证码或设备签名安全等级。
- 不修改权限、组织、工单状态和通知；只为 WEB 会话增加显式的持久登录标记。
- 不保存用户名对应的明文密码，不新增第三方身份服务。

## 影响文件

- `e-report-backen`：`LoginRequestDTO`、`AuthController`、`AuthSessionService`、`WebSessionCookieFactory`、Liquibase 044 及测试。
- `e-report`：登录页、认证上下文、PoW helper、版本元数据及测试。
- `e-report-app`：HTTP 刷新策略、认证 PoW、登录页、共享按钮、版本元数据及测试。
- `deploy/dedicated-cloud/e-report-test.yaml`：测试候选不可变镜像 tag。

## 验收标准

- Android Access Token 过期后访问 `/auth/me` 会单飞刷新并继续请求；仅 400/401/403/409 等终止性刷新失败清理本地会话。
- Android 杀进程后重启仍进入原账号；断网冷启动保留本地身份并允许网络恢复后继续使用。
- WEB 勾选“记住登录状态”返回带 `Max-Age=604800` 的 HttpOnly Cookie；取消勾选不返回持久 `Max-Age`。
- APP/WEB PoW 使用本地批量摘要，挑战协议与服务端验证结果不变。
- 登录按钮显示安全校验、认证和进入系统阶段；共享长操作按钮显示转圈并禁用重复点击。
- 三端测试、lint/typecheck、构建、版本契约、测试环境 WEB smoke 和 Android 模拟器冷启动回归全部通过。

## 测试方式

- Backend：`gradlew test`、`gradlew bootJar`。
- WEB：`npm test`、`npm run lint`、`npm run build`。
- APP：`npm test`、`npm run typecheck`、`npm run doctor`、版本契约和 Android release 构建。
- 测试环境：认证 Cookie 属性、登录阶段耗时、APP 登录后杀进程/冷启动、Access Token 刷新和退出登录。
