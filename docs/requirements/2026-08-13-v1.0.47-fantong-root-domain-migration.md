# v1.0.47 fantong 根路径破坏性迁移

## 目标

将生产入口整体迁移至 `https://e-report.fantong.eu.org:60443/`，移除所有用户可见的 `/e-report` 前缀，并下架旧 `omnnu.xyz` e-report 域名。

## 范围

- WEB、PWA、Android、Spring Boot context path、Nginx、K8S HTTPRoute、TLS、CORS、发布脚本和 E2E 防误测规则。
- Cloudflare 310 账号新增 `e-report.fantong.eu.org` DNS；生产集群新增精确 TLS 证书和 Gateway listener。
- 新稳定契约：WEB `/`、API `/api`、APK `/download/android`。
- APK 继续使用 Cloudflare 348 账号 R2，不迁移 Bucket、对象或分发域名。

## 非目标

- 域名迁移本身不新增数据库变更；本次合并上线仍需执行已批准的 v1.0.47 `030-user-transfer-v2` Liquibase 变更集。
- 不重命名 K8S 资源、镜像仓库、Android package、R2 key 或主机数据目录。
- 不保留旧域名、旧 API/WEB 路径的 redirect、rewrite 或运行时兼容层；旧路径仅返回 `410 Gone`。

## 影响文件

- `e-report/`：Vite base、Router、PWA、页面资源、Nginx。
- `e-report-app/`：公开 endpoint、发布脚本、请求签名测试。
- `e-report-backen/`：Servlet context path、CORS、公开链接测试。
- `deploy/`：生产/测试清单、Gateway、cert-manager、旧 relay 清理。
- `scripts/`：隔离测试与生产只读巡检 host allowlist。

## 验收标准

- 新域名根页面、深层 SPA 路由、PWA 资源、`/api`、附件和 `/download/android` 均可用。
- APK 固定入口跳转至 348 R2，支持 HEAD、Range 206，下载文件 SHA-256 与发布记录一致。
- v1.0.47 APK 在 Android 模拟器完成安装、启动、登录和核心页面 smoke。
- 旧 e-report 主域与 relay 的 DNS 记录不存在，e-report HTTPRoute 不再包含旧 hostname。
- 生产数据库完成部署前快照，Pod Ready，日志无新增 ERROR/FATAL，关键只读 API 正常。
- 测试命名空间在生产完成 `030` 后恢复每日同步，且同步后通知、日报派发和诊断事件表保持清空。

## 测试方式

- WEB：test、lint、build、Nginx 配置验证、浏览器根路径和深层路由 smoke。
- APP：test、typecheck、doctor、release APK 构建、签名/版本/端点检查、模拟器安装 smoke。
- 后端：Gradle 全量测试、bootJar、测试命名空间 API smoke。
- 生产：DNS/TLS/HTTPRoute 状态、HTTP HEAD/Range/SHA、K8S rollout、日志与只读业务 API。
