# 主体服务图片脱敏提交开关

## 目标

在主体服务配置中心提供租户级“允许提交新的图片脱敏任务”开关。开关关闭时，主体服务不再把新的图片脱敏任务置为可领取状态；已经提交给图像 worker 的任务继续完成。

## 范围

- Backend：配置目录、动态提交判定、待提交任务状态、巡检恢复、附件安全访问约束。
- WEB：系统配置中心提供布尔开关的可读可编辑交互。
- Liquibase：为 `image_redaction_jobs` 增加 `DEFERRED` 状态。

## 非目标

- 不修改 `media-image-worker` 的代码、依赖、模型或部署镜像。
- 不取消、暂停或重置已经处于 `QUEUED`、`PROCESSING`、`RETRY_PENDING` 的任务。
- 不把原图路径返回给客户端；开关关闭不等于关闭脱敏安全约束。

## 行为契约

1. 开关开启：新任务状态为 `QUEUED`，worker 可正常领取。
2. 开关关闭：新任务状态为 `DEFERRED`，主体服务保存源文件但附件只引用脱敏占位路径；原图不参与展示和下载。
3. 关闭期间已存在的 `QUEUED/PROCESSING/RETRY_PENDING` 任务保持原状态，worker 继续处理。
4. 重新开启：主体服务巡检将批量 `DEFERRED` 转为 `QUEUED`，不触碰已完成或失败任务。
5. 配置为租户级，组织级配置列表不允许覆盖该开关，避免同一租户后台任务因组织上下文产生不一致。

## 验收标准

- 配置中心可看到并修改开关，保存后无需重启即可影响后续上传。
- 关闭时上传完成返回待提交状态，不能通过附件详情、工单详情或 ZIP 下载获得原图。
- 关闭前已经进入队列的任务仍可被 worker 处理。
- 重新开启后待提交任务可进入队列；重复巡检幂等。
- Liquibase 迁移可重复执行且生产已有任务状态不变。
- Backend 单元测试、WEB lint/build 通过；`media-image-worker` 工作树零改动。
