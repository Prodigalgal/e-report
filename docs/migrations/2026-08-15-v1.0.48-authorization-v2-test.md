## 系统账号与授权上限

- `SUPER_ADMINISTRATOR`：平台最高系统身份，绑定平台租户与全市授权基线；SYSTEM 来源只读，只有该上限能够管理平台级授权。
- `DEFAULT_ADMINISTRATOR`：市公司根组织级系统身份，默认覆盖全市公司，但不自动获得平台租户管理能力。
- bootstrap 配置只用于首次创建；数据库已有口令和主动授权优先，应用重启不会按 ENV 重置账号。
- 系统基线按 assignment 来源整体判断可见性。只要来源内任一 Grant 超过操作者委派上限，整个来源名称和范围都隐藏，只显示“另有 N 条上级授权”。
- WEB 与 APP 均验证：`superAdmin` 可管理平台与市公司系统能力；`admin` 查看 `superAdmin` 时只看到可覆盖的市公司基线、看不到平台岗位名称且没有调整入口。

- 导入预览按脱敏账号归组，不在预览表或结构化 JSON 中保存完整手机号和默认口令。

## UI/UX 证据

- 授权编辑器直接展示扁平原子权限清单，不再按岗位模板或授权来源分组；来源只作为每条权限的审计备注。
- 岗位模板只负责批量把模板规则加入待变更清单，单条追加用于精细授权；当前权限仅提供逐条调整和撤销，不再展示“升级岗位”或“撤销来源”。
- 授权编辑采用“编辑权限清单、确认变更”两步流程；选择单条权限后候选列表自动折叠，直接进入关系、范围、有效期和原因设置。
- 用户详情页所有操作集中在唯一操作区，WEB 与 APP 的同级按钮统一颜色、尺寸和状态，不再默认高亮“调整授权”。
- 查询类工单权限默认使用“本人组织及下级 + 范围内全部工单”；只有支持多种对象关系时才显示“可操作工单”选择，固定关系由系统自动确定。
- `REPORTER` 显示为“本人提单”，`PARTICIPANT` 显示为“本人参与处理”，两者互不包含。
- 用户列表最多展示 3 个岗位，其余使用“另有 N 个”，WEB 与 APP 均通过实机/浏览器检查。
- 批量治理移动端最近任务不再使用宽表格，状态、时间和有效/错误计数改为可扫读卡片；底部按钮统一尺寸并按两列排列，统计标签显式换行且不再溢出。
- Figma 文件已建立，但 Starter View MCP 写入额度在本轮触顶；可执行设计基线以仓库内 `authorization-policy-v2-ui-preview.html` 和 PNG 原型为准。

## 已处理的验收问题

1. 低权限管理员曾能看到高权限来源名称。后端改为 assignment 来源整体裁剪，并新增集成测试。
2. 旧前端 runtime Dockerfile 曾把根路径构建复制到 `/e-report`，造成 readiness 403。镜像路径已深度迁移为根目录 `/usr/share/nginx/html`，不保留旧路径兼容。
3. Expo 补丁升级后旧 CMake 缓存缺少 worklets codegen。通过官方 codegen 任务重建，不增加兼容代码。
4. 新 Expo Maven 本地产物被 dependency verification 正确拦截。已同步 Gradle lock 与 SHA256 metadata，并再次通过供应链审计。
5. 批量治理按钮仍写死“V2”。已改为“下载最新模板”，后端文件名和元数据继续明确 V3。
6. 单条权限曾只能撤销后新增。现在 WEB、APP 和批量工作簿都支持原地选择目标原子权限，后端以不可变历史方式完成替换。
7. OCI archive 首次导入测试节点时未保留顶层 index，`imagePullPolicy: Never` 拒绝启动；测试环境先回滚到旧镜像，再以全新 digest 和 `--index-name` 正确导入，最终 Pod 均 Ready 且重启为 0。
8. 初版清单仍按授权来源渲染卡片，造成岗位模板被误解为运行时角色。最终改为扁平 `PermissionGrant` 清单，来源只保留审计信息。
9. 导入预览曾只提供整条命令摘要，无法确认具体改了什么。后端现在返回结构化字段与原子权限 Diff，WEB 逐项渲染旧值/新值。
10. 取消任务后最近任务状态曾滞后，移动端统计标签也因 MUI `Stack` 简写未生效而横向溢出。现已同步更新任务缓存，并使用显式响应式布局与 `sx.flexWrap` 修正。
11. 调整既有长期授权时，历史 `validFrom` 曾被误用“新授权开始时间”规则校验，导致未填写到期时间仍提示生效时间过早。现在只有显式修改开始时间才应用新授权时间校验；未填写开始时间保留历史值，未填写到期时间继续表示长期有效。
12. WEB 错误格式化器曾把后端统一返回的空 `errors={}` 当成字段错误，覆盖具体业务原因。现在仅非空字段错误进入字段错误分支，其余错误直接展示后端中文原因并保留错误编号。

## 长期授权时间缺陷复验

- 复现错误编号 `f4b88be7-797b-482d-aa01-e31c705a9a73`，后端日志确认原因为“授权生效时间不能早于当前时间”，不是权限委派边界或长期授权限制。
- 测试环境使用市公司管理员对示例报单员创建同类预览：追加“安装包对象删除”长期权限，同时调整历史“破损箱体更换查看”长期权限，接口返回 200。
- 预览结果包含 1 条 ADD 和 1 条 UPDATE；历史权限的 `validFrom=2026-08-06T08:41:40` 在调整前后保持一致，两项 `expiresAt` 均为 `null`。
- 本次只创建 10 分钟有效的不可变预览计划，未调用 apply 接口；复核示例报单员 `authorizationVersion=10`、原关系仍为 `REPORTER`、既有安装包对象删除授权数量未变化。
