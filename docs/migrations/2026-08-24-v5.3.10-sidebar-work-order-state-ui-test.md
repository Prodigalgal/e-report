## 行为变化

- WEB 桌面工单列表的类型、优先级标签改由同一个横向 `Stack` 承载，统一高度、间距和垂直中线；移除优先级标签的额外上边距。
- 优先级缺省文案统一从展示目录取得，不再可能把内部枚举 `ROUTINE` 暴露给用户。
- 工单列表以主状态标签表达流程阶段，以时钟文字表达 SLA；超时只显示一次，闭环工单不再显示无意义时限。
- WEB 移动卡片、APP 卡片和管理详情复用同一套工单状态、优先级、SLA 颜色与文案规则。
- WEB 390px 页面无横向溢出；标题、筛选区、状态区和操作区保持清晰层级。
- 管理侧栏的展开/收起宽度、主内容偏移和图标中心同步过渡，收起后图标保持居中。

## 已知非阻断项

- Vite 主入口约 583 kB，仍有大 chunk 提示，后续性能专案可继续拆分。
- APP 构建包含 Expo/React Native 上游弃用提示和 Gradle 10 兼容提示，当前不影响 5.3.10 构建及运行。
- 通用镜像脚本尝试刷新未变更的 MySQL 基础镜像时，Oracle Yum 源超时；本版本不变更或部署数据库镜像，实际 Backend、Frontend、数据库工具 OCI 已分别封存和校验。
- Backend 启动仍有 `TenantExecutionContext` 作为基础设施 Bean 的 BeanPostProcessor 时序警告，本版本未改变该行为，需在后续后端整理中单独消除。

## 回滚

- 测试环境出现运行阻断时，将 Backend、Frontend 回滚至测试环境上一不可变镜像；若需要回到本专案开始前的稳定视觉基线，使用 `5.3.4`。
- 本版本无数据库迁移，回滚不涉及数据恢复。
- 用户明确验收前，不得将 `5.3.10` 切换到生产。
