# 6.0.3 清理无效用户导入结果权限

- Liquibase：`2026-09-29-072-remove-unused-user-import-result-permission`
- 目标：移除没有下载接口消费者的 `user:import:result:download`。实际导入错误文件仍由 `user:import:error-report:download` 控制。
- 变更：从当前权限目录和内置用户导入模板中删除该权限；迁移删除其 API Token scope、Grant、岗位模板规则和权限目录记录。
- 影响：旧 Token 失去这个无效 scope；历史 Grant 和模板规则不再保留。该权限此前没有运行时接口消费者。
- 回滚：数据清理不可逆；不能通过回滚应用代码恢复已删除的授权记录。
- 状态：迁移已编写，尚未在测试库或生产库执行。
