# 4.2.0 权限系统 V3 与 PostgreSQL 联合迁移计划

## 状态与边界

- 状态：实施中。
- 功能架构：权限系统 V3。
- 当前最终制品版本：`4.2.0`，Android `versionCode=3002000`，`runtimeVersion=android-4.2.0-native3002000`；`4.0.0`、`4.0.1`、`4.1.0`、`4.1.1`、`4.1.2`、`4.1.3`、`4.1.4`、`4.1.5` 保留为不可覆盖的迁移测试候选。
- 首个运行目标：VPS `e-report-test`；用户终验前禁止切换生产。
- 生产源 MySQL 在切换完成前保持权威数据源；测试迁移关闭通知、日报和生产数据回写。

## 目标架构

1. Backend 目标运行时只连接 PostgreSQL，使用原生 `uuid` 与 PostgreSQL Driver。
2. 权限 V3 四平面继续由应用服务组合判定，PostgreSQL RLS 只强制租户边界。
3. 应用角色、结构所有者、迁移角色分离；应用角色不得具有 `BYPASSRLS`、建表或修改策略权限。
4. MySQL 历史 Liquibase 链冻结；PostgreSQL 使用当前最终模型生成单独 baseline。
5. MySQL 到 PostgreSQL 转换器独立运行，不进入应用正常启动路径，不形成双写或双数据库兼容层。

## 类型与语义映射

| MySQL | PostgreSQL | 规则 |
| --- | --- | --- |
| `BINARY(16)` UUID | `uuid` | 按现存 16 字节原样组成标准 UUID，不统一执行 time-part swap |
| `DATETIME(6)` 事件时间 | `timestamp(6) without time zone` | 保持现有 `LocalDateTime` 契约，源值和目标值都按 UTC 解释，迁移过程不得发生时区换算 |
| 纯本地日期/时间 | `date` / `time` | 不附加时区 |
| `LONGTEXT` | `text` 或 `jsonb` | 摘要、签名和审计原文保留 `text`；只把需要结构化查询的内容改为 `jsonb` |
| `LONGBLOB` | `bytea` | 仅迁移仍在数据库中的二进制数据；附件主体继续由 R2 承载 |
| MySQL 大小写不敏感唯一约束 | 表达式唯一索引 | 用户名、邮箱按规范化小写唯一；手机号按原值唯一 |
| `ON UPDATE CURRENT_TIMESTAMP` | 应用审计时间 | 领域实体显式更新时间，避免隐藏触发器副作用 |

## 数据迁移顺序

1. 租户组、租户、组织与用户。
2. 权限目录、岗位模板、数据范围、授权事实。
3. V3 管理域、保护、管理主体、委托和审批事实。
4. 工单、派单、回单、验收、事件、SLA、物料与附件元数据。
5. 配置、通知、会话、受信设备、API Token、导入导出任务、Outbox、可观测事件和安装包发布记录。
6. 外键延后校验并最终启用；序列、索引、RLS 和应用只读/读写角色最后建立。

## 迁移门禁

- 每张表记录源行数、目标行数、主键摘要和空值分布。
- 所有 UUID 字段执行二进制到文本再到二进制的往返校验。
- 验证外键孤儿为零，重点覆盖工单到附件、回单、派单、验收和授权事实。
- 用户名、手机号、邮箱、权限码、组织编码和工单编号唯一性保持一致。
- 密码哈希、Token 哈希和审计摘要不重新计算、不暴露原值。
- 测试环境通知、邮件、机器人、日报和生产回写保持关闭。
- 迁移重复执行不得重复插入；失败重跑从已记录的表/分片检查点继续。

## 切换与回滚

1. 进入维护态并拒绝新的业务写入。
2. 暂停定时任务、通知分发、Outbox 消费和测试空间同步。
3. 完成最终 MySQL 一致性备份并记录 binlog 位点。
4. 创建 PostgreSQL baseline，执行全量转换和校验。
5. 启动只连接 PostgreSQL 的 `4.2.0` Backend，完成 API、浏览器和 Android smoke。
6. 所有门禁通过后才开放写入。

开放写入前可直接回切只读源 MySQL。开放 PostgreSQL 写入后不得直接回切，否则会丢失增量；需要回滚时必须先停写并执行经过演练的反向增量恢复。

## 验收矩阵

- V3 管理上下级、同级隔离、自我提权、委托上限、有效期和审批职责分离。
- superAdmin、市公司、区县管理员、普通用户和 API Token 的 BOLA/BFLA 测试。
- 工单全状态、全角色、附件预览/下载、SLA、报表、导入导出和拼音搜索。
- RLS 跨租户读写拒绝，组织范围查询结果与迁移前一致。
- PostgreSQL 约束、慢查询、锁等待、连接池和核心 API P50/P95。
- Backend、WEB、APP 版本契约、SBOM、镜像和 Android 模拟器验证。
