# 3.0.0 权限体系 V3 测试迁移计划

## 环境边界

- 仅部署 `e-report-test`。
- 生产命名空间、生产数据库、生产 Redis 和生产镜像引用保持不变。
- 测试数据同步 CronJob 保持暂停。
- 邮件、钉钉、企业微信、日报、R2 发布和通知 Outbox 保持关闭。

## 数据迁移

1. 迁移前备份测试库授权、用户、组织、Token、会话和受信设备表。
2. Liquibase 创建 V3 表与约束。
3. 按租户和组织父子关系生成管理域。
4. 根据唯一 superAdmin 和组织默认管理员生成保护与管理主体。
5. 保留访问授权；按受控规则生成默认管理员的委托上限。
6. 输出跨区县、来源不明、超范围和同级管理冲突清单。
7. 校验无孤儿管理域、保护事实、委托来源或越界有效期。

- 测试环境使用迁移前数据库备份恢复。

- V3 迁移不进入生产，因此本阶段不修改生产回滚基线。
