## 功能验收

- 流式导出：用户分页 250 条，岗位来源、Grant 与组织范围批量加载；SXSSF 仅保留 200 行窗口，不在内存持有全量工作簿。
- 快照一致性：预检令牌绑定租户、操作者、筛选条件、数据摘要、计数和十分钟有效期；创建前、异步开始和写文件后均复核快照，变化时任务进入 `STALE`。
- 任务恢复：导出任务写入数据库，刷新后通过任务中心重新发现；排队任务可取消，客户端下载停止不会误杀已经生成的服务端文件。
- 失败结果：校验失败或执行失败会生成独立 `失败明细` XLSX；WEB 可分别筛选校验失败、执行失败，并通过鉴权下载错误文件。
- 权限边界：导入预览、执行、取消、模板下载、导出创建和结果下载按原子权限分别校验；撤销权限后不能继续读取历史任务结果。
- 租户公平：同租户最多 2 个未完成任务、同操作者最多 2 个未完成任务、同租户最多 1 个执行中任务；租户行悲观锁保证多副本一致。
