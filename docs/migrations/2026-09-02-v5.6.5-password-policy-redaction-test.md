- Liquibase：本版本不新增数据库迁移；复用现有附件、上传会话和图片脱敏任务表

## 本版本交付

1. 密码策略由后端统一执行，支持最小长度（8—100）及大写、小写、数字、特殊字符四项要求；平台默认值为 8 位且四项均开启。
2. 管理端新增密码策略配置面板，按平台、租户和组织作用域读取；组织配置可继承上级，也可由具备配置权限的管理员创建覆盖或恢复继承。
3. 用户创建、管理员重置密码、本人修改密码和租户初始化管理员均使用当前作用域策略；密码策略读取接口不要求客户端先完成强制改密流程。
4. 图片脱敏巡检按租户运行，使用 Redis 分布式锁和批量上限，复用已完成的上传会话关联图片脱敏任务；巡检不读写文件，不删除原图，不为缺少上传会话的附件伪造任务。
5. 图片检测结果先合并重叠框，再按比例做有限扩展（默认 5%，最大 16px），降低过度打码；路径匹配对 `_sanitized/` 使用显式转义，避免 SQL `_` 通配导致漏检。

- 按测试要求从 PostgreSQL 备份和生产上传根目录恢复 3 组已处理样本到 `e-report-test`；原图写入测试 VPS 的 `_quarantine`，派生图写入 `_sanitized`，生产数据库、生产文件和生产 Deployment 均未修改。

- 旧模型结果复核发现 2 组非品牌区域误判、1 组大面积过度打码；新增精度门控后，设备铭牌/按钮样本不再打码，真实品牌标签只覆盖窄区域。证据文件保存在本地 `test-results/v5.6.5-redaction-restore/precision-v2/`。
- 巡检日志同时暴露固定第 0 页的问题：前 100 条缺少上传会话的历史附件会使后续附件长期无法扫描。代码已改为按 UUID v7 主键游标分页，并补充跨批次单元测试；该修复尚未部署到新的测试候选。

## 发布边界与回滚

- 本候选仅用于测试验收，未部署生产，也未发布 APP 到下载中心。
- 测试镜像和 OCI 制品均使用不可变候选标签；`test-1`、`test-2`、`test-3` 保留，可按部署清单回滚。
- 现有用户密码不会被自动重置；策略只影响新建、重置和修改密码。
- 原始图片继续保留在 VPS 上传根目录，脱敏结果仅作为展示/下载派生文件；如巡检误判，可停用巡检开关并保留任务记录后人工复核。
