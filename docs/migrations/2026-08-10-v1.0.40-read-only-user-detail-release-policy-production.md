## 回滚点

- 应用回滚：将 Backend/Frontend 镜像回退到 1.0.39 标签；Liquibase 021 保留不会影响旧应用读取。
- 数据回滚：仅在确认需要删除新权限体系时，先删除策略角色的 Grant 与用户分配，再删除角色规则、角色和权限，随后清理授权缓存。
- 数据库恢复：使用本次备份的 `fault_reporter_db.sql.gz`；恢复前必须先停止 Backend 并再次备份当前数据。
- Android code40 与 R2 对象不可复用或覆盖；后续修复必须使用更高且对齐的 versionCode/versionName。
