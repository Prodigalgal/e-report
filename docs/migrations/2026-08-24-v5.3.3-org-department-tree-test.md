## 实现结果

- 组织和部门不再使用两个平铺区域，统一为“组织树定位 + 当前组织详情 + 部门树维护”的工作台。
- 两棵树均支持真实连接线、层级缩进、展开/收起、名称/编码搜索、当前节点选中态和状态识别。
- 组织节点显示下级组织与部门数量；部门节点显示下级部门数量，选中后集中展示上下级关系和可执行操作。
- 原有组织、部门生命周期操作与破坏性预览全部保留，操作入口由原子权限逐项控制。
- 只有部门查看权限时，页面根据接口已返回的部门构造只读组织入口，不请求不可见组织目录，也不显示空操作菜单。
- 390px 视口按组织树、组织详情、部门树纵向排列，没有横向溢出。
