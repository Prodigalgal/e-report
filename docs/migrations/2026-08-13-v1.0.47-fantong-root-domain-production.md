- 1.0.46 及更早客户端仍指向已下架旧域名，无法通过旧入口自更新，需要人工从新入口安装 1.0.47。
- 应用回滚：使用部署快照恢复 1.0.46 工作负载和旧 HTTPRoute；若恢复旧域名，还需单独重建 Cloudflare DNS 与旧证书路由。

- APK 对象按 versionCode 不可变；回滚发布策略时保留 R2 对象，撤销或调整数据库发布记录，不覆盖 code 47 对象。
