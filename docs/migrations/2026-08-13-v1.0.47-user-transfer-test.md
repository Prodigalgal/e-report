## 迁移内容

- 用 `role_bundle_grant_rules` 替换只表达角色关系的 `role_bundle_roles`，岗位模板规则可显式配置数据范围、组织锚点和有效期策略。
- 新增 `user_transfer_jobs` 和 `user_transfer_job_rows`，保存导入导出任务、预览快照、分页行结果、进度、幂等键和失败信息。
- 用户传输 V2 使用 UUIDv7 主键；导入动作拆为用户资料和授权调整两类事实，不再保留同步 V1 兼容层。
- 委派校验同时约束角色权限、数据范围和授权有效期。下级有效期上限取授予者能够完整覆盖该 Grant 的最早到期时间。
