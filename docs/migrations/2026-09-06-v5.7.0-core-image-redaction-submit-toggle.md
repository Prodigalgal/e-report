# v5.7.0 主体服务图片脱敏提交开关

## 变更

- 新增租户级配置 `media.image-redaction.submission-enabled`，默认 `true`。
- `image_redaction_jobs.status` 新增 `DEFERRED`，表示主体服务已保存源文件但尚未提交给图像 worker。
- 主体服务重新开启开关后，巡检任务按批次把 `DEFERRED` 转为 `QUEUED`。

## 数据安全

- `QUEUED`、`PROCESSING`、`RETRY_PENDING` 在关闭开关后保持原状态，图像 worker 不需要改造。
- `DEFERRED` 和没有关联任务的历史图片均不返回原图路径；附件下载只允许脱敏结果。
- 迁移只调整状态约束，不改写既有任务数据。
